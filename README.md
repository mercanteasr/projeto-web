Projeto de Programação Web Front-End

Projeto da disciplina de Programação Web Front-end. Site com página principal, página de cadastro e um painel admin com funcionalidades em JavaScript (cadastro, listagem, exclusão e pesquisa de usuários usando Local Storage).

Estrutura do projeto
├── imgs/            imagens dos produtos e do banner
├── index.html       página principal (produtos, categorias, carrinho e login)
├── cadastro.html    página de cadastro de usuário
├── login.html       página de login
├── admin.html       painel admin (cadastro, listagem, exclusão e pesquisa)
├── elements.css     estilos de todas as páginas
├── global.js        JavaScript do admin, carrinho, categorias, cadastro e login
└── README.md

Site publicado: https://mercanteasr.github.io/projeto-web/

Como abrir
Clone este repositório
Abra o arquivo index.html no navegador (ou use a extensão Live Server no VS Code)
