Projeto de Programação Web Front-End

Projeto da disciplina de Programação Web Front-end. Site com página principal, página de cadastro e um painel admin com funcionalidades em JavaScript (cadastro, listagem, exclusão e pesquisa de usuários usando Local Storage).

Estrutura do projeto
├── assets/
│   ├── css/
│   │   └── elements.css
│   └── js/
│       └── global.js
├── index.html
├── admin.html
└── README.md

Como abrir
Clone este repositório
Abra o arquivo index.html no navegador (ou use a extensão Live Server no VS Code)
